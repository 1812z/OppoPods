# 2026-09-28

## 新增「焦点通知」设置项（默认开启）

设置页「超级岛」选项上方新增开关，控制通知栏焦点通知的启用。

改动文件：
- `config/ConfigManager.kt` — `AppConfig.focusNotification = true`；`PREF_KEY_FOCUS_NOTIFICATION`；`focusNotification()` / `updateFocusNotification()`；writePrefs / readConfig(两处 copy) / changedFields(用于变更日志) 均已同步。
- `hook/MiBluetoothToastHook.kt` — 开关的实际控制点：
  - `onHook()` 开头提前 `return`，关闭时完全不注册 receiver / 不 hook 构造函数。
  - receiver 的 `chen.action.oppopods.updatepodsnotification` 分支：关闭时 `cancelNotification()` 撤掉已显示通知并 return。
- `ui/pages/SettingsPage.kt` — 新增 `focusNotification` / `onFocusNotificationChange` 参数，`SwitchPreference` 放在岛屿 Card 内、`island_mode` 上方。
- `ui/MainTabs.kt` — 两处（`MainTabsPage` 与私有 `SettingsTabPage`）加参数并透传。
- `ui/MainUI.kt` — 状态 + 回调，切换时 `broadcastConfigChanged(context, "com.xiaomi.bluetooth")`（与 islandMode 同 scope）。
- `res/values/strings.xml` + `res/values-zh-rCN/strings.xml` — `focus_notification` / `focus_notification_summary`。

注意：新增配置项需同时在 `readConfig` 的**两个** copy 分支（`directFakeDeviceId` 非空 / 为空）里补字段，否则从 JSON 读取时会被丢弃。

## jadx 侧情报：LC3 / LE Audio 模块

本项目 Kotlin 源码中**不存在** LC3 相关实现，仅有 `MiLinkServiceHook` 里 `isLeAudio` 返回 false。
